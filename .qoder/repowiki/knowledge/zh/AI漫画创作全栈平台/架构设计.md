- **启动引导机制**：利用 Next.js `instrumentation.ts` 在服务端启动时执行 `bootstrap`，统一完成数据库迁移、AI提供商初始化及任务队列启动。
- **异步任务编排**：采用基于 SQLite 轮询的内存任务队列（`task-queue`），将耗时的 AI 处理（如分镜拆分、视频生成）解耦为后台 Worker 任务，避免阻塞 HTTP 请求。
- **数据与逻辑耦合**：通过 Drizzle ORM 统一管理应用状态，`pipeline` 模块直接操作数据库表（如 `shots`, `tasks`）实现业务流转，形成紧密的全栈闭环。
- **多平台 Agent 抽象**：通过 `agent-bindings` 表与 `provider-factory` 动态路由至 Bailian、Coze 或 Dify 平台，实现工作流定义的灵活切换。
